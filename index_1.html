One step left: connect the shared database

This page is running in local-only mode — changes stay on this device. To make it sync for everyone, paste your Firebase config into the FIREBASE_CONFIG block near the bottom of index.html, then re-upload it.

  1. Create a free project at console.firebase.google.com (no card needed).
  2. In the left menu choose Build › Realtime Database → Create Database → pick a location → Start in test mode.
  3. Open Rules and replace them with the block below, then Publish.
  4. Go to Project settings › General, scroll to Your apps, add a Web app, and copy the firebaseConfig values.
{
  "rules": {
    "boards": {
      "$board": { ".read": true, ".write": true }
    }
  }
}

These rules let anyone who knows the database URL read and write this board. That matches how you are using the link, but do not put anything sensitive in it.
